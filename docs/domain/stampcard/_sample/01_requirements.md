# スタンプカード — 要件定義

## 受け取った要求

> 「注文1回につきスタンプを1個押したい。
> 10個たまったら、次の注文でハンバーガー1つが無料になる。
> スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
> お客さんは、いま何個たまっているかをアプリで見たい。」

## 確認したいこと（質問リスト）

| 質問 | 今回の回答（仮） |
|---|---|
| 1日にスタンプを押せる回数に制限はあるか | なし。注文1回につき1個 |
| 10個で無料になるハンバーガーは、どれでもよいか | どれでもよい |
| 注文がキャンセル・未受け取りになった場合、スタンプはどうするか | そのスタンプを消す |
| スタンプカードはアプリのどこで見せるか | ログイン後の画面で見せる |
| 「最後の注文から1年」とは、直近の注文から1年間は過去のスタンプも有効という意味か。それともスタンプごとに押した日から1年で失効するか | **スタンプごとに、押した日から1年で失効する** |
| 10個たまって得た無料特典自体に有効期限はあるか | なし |

要求文の「有効期限は最後の注文から1年」は、2 通りに読めるため確認した。**確認の結果「スタンプごとに1年」に確定** している。以降の資料はすべてこの前提で書く。

## 業務フロー

```
[会員]
 1. アプリを開き、ログインする（スタンプカードも見られる）
 2. 支払うタイミングで、スタンプが1個たまる
 3. スタンプが10個たまっていれば、購入時に無料で受け取るハンバーガーを1つ選べる
    （消費した10個は使用済みにし、新しい1個からカウントを再開する）

[店舗スタッフ]
 4. 店舗購入の際は、スタンプカードをスキャンして、アプリのスタンプカードに反映させる

[システム]
 5. 注文がキャンセル、または未受け取りになった場合、その注文で押したスタンプを消す

[例外・ルール]
 - スタンプは店舗をまたいで共通（店舗ごとに分けて数えない）
 - スタンプごとに、押した日から1年で失効する
 - 10個たまって得た無料特典自体には有効期限がない（個々のスタンプの失効とは別）
 - 1つの注文で押されるスタンプは1個。注文金額や点数によって増えない
```
