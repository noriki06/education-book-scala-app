# <スタンプ> — 要件定義

## 受け取った要求
「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

### 追加の要求
「特典の種別ごとに有効期限を設定したい。
特典は全額無料・半額・金額割引（円）の3種類にしたい。特典だけの注文はスタンプ付与なし。
管理側で特典の利用実績を集計したい。」

### 追加の要求による差分の見方
行の末尾（表では「由来」列）に、**追加の要求で何が動いたか**を示す。

| 印 | 意味 |
|---|---|
| 〔追加要求〕 | 追加の要求で**新しく入った**もの。当初の要求には無かった |
| 〔追加要求で変更〕 | 当初の要求にもあったが、追加の要求で**内容が変わった**もの |
| 印なし／「当初」 | 当初の要求のまま。追加の要求では動いていない |

## 確認したいこと（質問リスト）
| 質問 | 今回の回答（仮） | 由来 |
|---|---|---|
| カードの有効期限はどう決まるか | 種別（マスタ）が種別ごとに保有期間を持つ（例：通常＝1年、サマースタンプ＝3ヶ月）。カードができた日（＝会員がその種別で最初のスタンプを得た日）＋ その期間で確定 | 追加要求で変更（当初は「最後の注文から1年」の一律） |
| 満杯になったカード（特典）の有効期限は | カードの有効期限 ＋ 種別が定める延長期間（例：＋1ヶ月）。早く貯めた会員ほど特典を使える残り期間が長くなる | 追加要求 |
| 会員は複数の種別のカードを同時に持てるか | スタンプを貯められるカードは常に1枚。ただし期間限定に参加している間は、通常スタンプのカードを**中断した状態で1枚保持する**。並行して貯めることはできない | 追加要求（種別が複数になったため） |
| 期間限定に参加したら、それまでに貯めたスタンプはどうなるか | 通常スタンプのカードはそのまま中断して保持する。期間限定のカードは別に1枚できて、スタンプは0個から数え直す。期間限定が終わったら、中断していたカードの続きから再開する | 追加要求 |
| 中断していた分の有効期限はどうするか | 再開したときに、実際に中断していた日数を有効期限に加算する。中断中は期限切れにしない | 追加要求 |
| 1人が同じ種別のカードを何枚まで作れるか | 種別ごとに発行上限を持つ。通常スタンプは上限なし（満杯になったら2枚目・3枚目と続く）。期間限定の種別は1枚だけ（1開催につき1枚。使い切っても期限切れになっても、同じ開催に再参加はできない） | 追加要求 |
| 特典はどんな種類があり、どの商品にどう適用されるか | 全額無料・金額割引（円）の2種類。種別ごとに1つ設定する。半額は対象商品の価格の半分を割引額として入れて表す。対象商品は種別ごとに1つ決める（商品側には何も持たせない）。対象商品1点に対して1つ適用する | 追加要求で変更（当初は「ハンバーガー1つ無料」のみ） |
| 特典のみの注文でもスタンプは付与されるか | 付与しない。特典対象以外の商品が1つでも含まれる注文には、通常どおり1個付与する | 追加要求 |
| カードの状態はどう表すか | 収集中／特典獲得／使用済み／期限切れの4値の区分値で持つ。管理側が特典の利用実績を集計したいという要求があるため | 追加要求（集計の要求から） |
| スタンプについて会員ができる操作は？ | 自身の有効スタンプ数・履歴の閲覧と、必要数が貯まった際の特典利用のみ | 当初 |
| スタンプ付与のタイミングは？ | 商品を受け取り完了した際に付与 | 当初 |
| 業務の人はカードを何と呼んでいるか | 要求文にあるのは「スタンプ」のみ。カードの呼称は確認できていないため、仮に「リワードカード」とする | 当初 |

## 業務フロー

[本部]

1. リワードカードの種別（名称・配布期間・必要スタンプ数・カードの有効期間・特典の延長期間・発行上限・特典の種類）を決める。〔追加要求〕

[会員]

2. アプリを開き、現在のスタンプ情報の表示をリクエストする。

[システム]

3. 会員のリワードカードの有効期限を確認する。
4. 期限を過ぎていれば有効スタンプ数を0として返す、
   期限内であれば有効なスタンプ数と、満杯のカードがあればその特典の有効期限をアプリに返す。〔追加要求で変更：特典の有効期限を返すようになった〕

[会員]

5. 画面に表示された「現在の有効スタンプ数」「カードの有効期限」「特典の有効期限」を確認する。〔追加要求で変更：特典の有効期限を表示するようになった〕
6. 商品をカートに入れる。（必要数のスタンプがたまっていれば、注文時に特典を選べる）
7. 注文を確定し、決済を完了する。

[システム]

8. 特典を利用した場合、注文確定のタイミングで、「特典獲得」の状態にある未使用のリワードカードのうち
   最も古い1枚を「使用済み」とする。〔追加要求で変更：状態が区分値になり、対象が複数枚から1枚選ぶ形になった〕
9. 特典を利用した注文がキャンセルされた場合、そのカードを「未使用」に戻す。〔追加要求で変更：状態を戻す操作になった〕

[店舗スタッフ]

10. 商品を会員に受け渡す。

[システム]

11. 受け渡し完了のタイミングで、特典対象以外の商品が含まれていれば、その注文にスタンプを1個発行する。〔追加要求で変更：特典だけの注文を除外するようになった〕
12. 押す先は、その会員が持つ、期限内・未使用・満杯でないカード。
    無ければ、配布期間内であることを確認して新しいカードを作る。〔追加要求で変更：配布期間の確認が入った〕

[会員]

13. 期間限定の種別が開催中で、まだその種別のカードを1枚も持っていなければ、参加するかどうかを選ぶ。〔追加要求〕

[システム]

14. 参加を選んだ場合、いま貯めているカードを中断し、期間限定のカードを新しく1枚作る。
    以後のスタンプは期間限定のカードに0個から貯める。〔追加要求〕
15. 期間限定のカードが満杯になるか期限切れになった時点で、中断していたカードを再開する。
    実際に中断していた日数を、そのカードの有効期限に加算する。〔追加要求〕

[例外・ルール]

- カードの有効期限は、できた日 ＋ 種別が定める有効期間で確定し、以後延長しない。
  中断していたカードを再開したときだけ、中断していた日数を加算する。〔追加要求で変更〕
- 満杯になったカードの特典は、カードの有効期限 ＋ 種別が定める延長期間まで使える。
  早く貯めた会員ほど、使える残り期間が長い。〔追加要求〕
- スタンプを貯められるカードは常に1枚。複数の種別を並行して貯めることはできない。
  中断中のカードを別に1枚まで持てる。満杯になったカードは、使うまで複数枚たまることがある。〔追加要求〕
- 1人が同じ種別のカードを何枚まで作れるかは、種別が定める発行上限で決まる。
  通常スタンプは上限なし。期間限定の種別は1枚だけ。〔追加要求〕
- 期間限定に参加すると、通常スタンプのカードは中断される。中断中のカードにはスタンプを押さない。
  スタンプを貯められるカードは、中断していないカード1枚だけ。〔追加要求〕
- 中断中のカードは期限切れにしない。再開して中断日数を加算してから、期限を判定する。〔追加要求〕
- 期間限定のカードが満杯になった後のスタンプは、中断していた通常スタンプのカードに戻して押す。
  同じ開催の2枚目は作らない。使い切ったか期限切れになったかは問わず、再参加もできない。〔追加要求〕
- 中断中のカードは常に最大1枚。中断中にさらに別の種別へ参加することはできない。〔追加要求〕
- 配布期間が終わっても、すでにできているカードは有効期限まで使える。終わるのは新規作成だけ。〔追加要求〕
- 新しいカードを作れるのは、種別の配布期間中で、かつ発行上限に達していない場合に限る。〔追加要求〕
- 1枚に押せるスタンプは種別が定める必要数まで。1回の注文で使えるカードは1枚まで。〔追加要求で変更：必要数が種別ごとになった〕
- 特典対象の商品しか含まない注文にはスタンプを付与しない。
  対象外の商品が1つでも含まれていれば1個付与する。〔追加要求〕
- 特典は対象商品1点に1つ。対象商品の代金を超えて割り引かない（マイナスにしない）。
  対象かどうかは種別（リワード）側で決める。種別が対象商品を1つ持ち、商品側には何も持たせない。〔追加要求〕
- 全店舗の注文がスタンプ付与の対象になり、貯まったスタンプはどの店舗でも使える。
- スタンプの消費は注文確定時、付与は受け渡し完了時。
  消費は「使う宣言」なので早めに押さえ、付与は「受け取った事実」への対価なので後になる。
