# <スタンプカード> — 要件定義

## 受け取った要求
「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

### 追加の要求（ボスからのレビューで判明）
「保有スタンプはマスタで管理したい。スタンプカードの種別ごとに有効期限を設定したい。
特典は全額無料・半額・金額割引（円）の3種類にしたい。特典だけの注文はスタンプ付与なし。
管理側で特典の利用実績を集計したい。」

このレビューにより、当初の「スタンプカード1種類・無料特典1種類」という前提が崩れた。
種別（マスタ）を新設し、種別ごとに有効期限・特典内容が変わる設計に組み替える。

## 確認したいこと（質問リスト）
| 質問 | 回答 |
|---|---|
| カードの有効期限はどう決まるか | **種別（マスタ）が種別ごとに保有期間を持つ**（例：通常＝1年、サマースタンプ＝3ヶ月）。<br>カードができた日（＝会員がその種別で最初のスタンプを得た日）＋ その期間で確定し、以後延長しない。<br>~~旧回答（付与のたびに「その日 ＋ 1年」へ一律延長）は廃止~~ |
| 満杯（10個）になったカード（特典）の有効期限は | **カードの有効期限 ＋ 種別が定める延長期間**（例：＋1ヶ月）。早く10個貯めた会員ほど特典を使える残り期間が長くなる |
| 会員は複数の種別のカードを同時に持てるか | **持てない。同時に持つカードは常に1枚。**（詳細は [例外・ルール] を参照） |
| 特典はどんな種類があり、どの商品にどう適用されるか | **全額無料・半額・金額割引（円）の3種類。** 種別ごとに1つ設定する（割引額は円）。<br>対象になるかは**商品（`MenuItem`）側のフラグ**で判定する（種別には依らない）。対象商品1点に対して1つ適用する |
| 特典のみの注文でもスタンプは付与されるか | **付与しない。** 特典以外の商品が1つでも含まれる注文には、通常どおり1個付与する |
| スタンプカードの使用状態はどう表すか | **使用済み／未使用の区分値で持つ**（→ 03_design.md）。管理側が特典の利用実績を集計したいという要求があるため |
| スタンプについて会員ができる操作は？ | 自身の有効スタンプ数・履歴の閲覧と、10個貯まった際の特典利用のみ（変更なし） |
| スタンプ付与のタイミングは？ | 商品を受け取り完了した際に付与（変更なし） |

[本部]

1. スタンプカードの種別（名称・配布期間・必要スタンプ数・カードの有効期間・特典の延長期間・特典の種類）を決める。

[会員]

2. アプリを開き、現在のスタンプ情報の表示をリクエストする。

[システム]

3. 会員のスタンプカードの有効期限を確認する。
4. 期限を過ぎていれば有効スタンプ数を0として返す、
   期限内であれば有効なスタンプ数を算出してアプリに返す。

[会員]

5. 画面に表示された「現在の有効スタンプ数」と「有効期限」を確認する。
6. 商品をカートに入れる。（スタンプが10個たまっていれば、注文時に特典を選べる）
7. 注文を確定し、決済を完了する。

[システム]

8. 特典を利用した場合、注文確定のタイミングで、10個揃った未使用のスタンプカードのうち
   最も古い1枚を「使用済み」とする。
9. 特典を利用した注文がキャンセルされた場合、そのカードを「未使用」に戻す。

[店舗スタッフ]

10. 商品を会員に受け渡す。

[システム]

11. 受け渡し完了のタイミングで、特典のみの注文でなければ、その注文にスタンプを1個発行する。
    押す先は、その会員が持つ、期限内・未使用・満杯でないカード（常に1枚まで）。
    無ければ、通常の種別の配布期間内であることを確認したうえで新しいカードを作る。
    新しいカードの有効期限は「その日 ＋ 種別が定める有効期間」で確定する。
    このとき期間限定の種別（サマースタンプ等）が開催中で、会員がまだ参加を選んでいなければ、
    参加するかどうかを選べる。参加を選ぶと、そのカードの種別が期間限定の種別に切り替わり、
    必要スタンプ数・特典・有効期限（いまの有効期限 ＋ 開催期間）が以後その種別の定める値になる。
    同じ開催中は、これ以降選択画面を出さない。

[例外・ルール]
- カードの有効期限は、できた日（＝最初のスタンプを得た日）＋ 種別が定める有効期間で確定し、
  以後延長しない。新しいカードを作れるのは種別の配布期間中に限る（期間の外では作らない）。
- **会員が同時に持てる進行中のカードは常に1枚。** 複数の種別を並行して貯めることはできない。
  期間限定の種別が開催されている間にスタンプが付与されるときは、まだ参加を選んでいなければ選択できる。
  参加を選ぶと、いま持っているカードの種別がその期間限定の種別に切り替わる
  （必要スタンプ数・特典の内容は、以後その期間限定の種別が定める値になる）。
  有効期限は上書きではなく、いまの有効期限に開催期間の長さを足して延長する（特典の有効期限も同様に延びる）。
  一度参加を選んだら、その開催中は選択画面を出さない。参加しなければ何も変わらない。
- 満杯になったカードの特典の有効期限は、カードの有効期限 ＋ 種別が定める延長期間で確定する。
  カードができた日が早い会員ほど、特典を使える残り期間が長い。
- スタンプカードの単位: 1枚に押せるスタンプは種別が定める必要数（例：10個）まで。
  満杯になった後のスタンプは新しいカードに押される。1回の注文で使えるカードは1枚まで
  （満杯のカードを複数持っていても、特典が使えるのは1個）。
- 特典のみの注文（特典対象の商品しか含まない注文）にはスタンプを付与しない。
  特典対象以外の商品が1つでも含まれていれば、通常どおり1個付与する。
- 特典は対象商品1点に対して1つ適用する。全額無料・半額・金額割引（円）のいずれも、
  対象商品の代金を超えて割り引かない（マイナスにはしない）。対象になるかは商品側のフラグで判定する。
- 店舗共通利用： 全ての店舗の注文がスタンプ付与の対象となり、貯まったスタンプはどの店舗でも利用できる。
- スタンプの消費は注文確定時、付与は受け渡し完了時。消費は「使う宣言」なので早めに押さえ、
  付与は「受け取った事実」への対価なので後になる。
