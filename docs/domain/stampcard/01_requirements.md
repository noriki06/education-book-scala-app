# <リワードカード> — 要件定義

## 受け取った要求
「注文1回につきスタンプを1個押したい。
10個たまったら、次の注文でハンバーガー1つが無料になる。
スタンプは店舗をまたいで共通。有効期限は最後の注文から1年。
お客さんは、いま何個たまっているかをアプリで見たい。」

### 追加の要求
「特典の種別ごとに有効期限を設定したい。
特典は全額無料・半額・金額割引（円）の3種類にしたい。特典だけの注文はスタンプ付与なし。
管理側で特典の利用実績を集計したい。」

## 確認したいこと（質問リスト）
| 質問 | 今回の回答（仮） |
|---|---|
| カードの有効期限はどう決まるか | 種別（マスタ）が種別ごとに保有期間を持つ（例：通常＝1年、サマースタンプ＝3ヶ月）。カードができた日（＝会員がその種別で最初のスタンプを得た日）＋ その期間で確定 |
| 満杯になったカード（特典）の有効期限は | カードの有効期限 ＋ 種別が定める延長期間（例：＋1ヶ月）。早く貯めた会員ほど特典を使える残り期間が長くなる |
| 会員は複数の種別のカードを同時に持てるか | 持てない。貯めている途中のカードは常に1枚。複数の種別を並行して貯めることはできない |
| 特典はどんな種類があり、どの商品にどう適用されるか | 全額無料・金額割引（円）の2種類。種別ごとに1つ設定する。半額は対象商品の価格の半分を割引額として入れて表す。対象商品は種別ごとに1つ決める（商品側には何も持たせない）。対象商品1点に対して1つ適用する |
| 特典のみの注文でもスタンプは付与されるか | 付与しない。特典対象以外の商品が1つでも含まれる注文には、通常どおり1個付与する |
| カードの状態はどう表すか | 貯め中／必要数を満たした／使用済み／期限切れの4値の区分値で持つ。管理側が特典の利用実績を集計したいという要求があるため |
| スタンプについて会員ができる操作は？ | 自身の有効スタンプ数・履歴の閲覧と、必要数が貯まった際の特典利用のみ |
| スタンプ付与のタイミングは？ | 商品を受け取り完了した際に付与 |
| 業務の人はカードを何と呼んでいるか | 要求文にあるのは「スタンプ」のみ。カードの呼称は確認できていないため、仮に「リワードカード」とする |

## 業務フロー

[本部]

1. リワードカードの種別（名称・配布期間・必要スタンプ数・カードの有効期間・特典の延長期間・特典の種類）を決める。

[会員]

2. アプリを開き、現在のスタンプ情報の表示をリクエストする。

[システム]

3. 会員のリワードカードの有効期限を確認する。
4. 期限を過ぎていれば有効スタンプ数を0として返す、
   期限内であれば有効なスタンプ数と、満杯のカードがあればその特典の有効期限をアプリに返す。

[会員]

5. 画面に表示された「現在の有効スタンプ数」「カードの有効期限」「特典の有効期限」を確認する。
6. 商品をカートに入れる。（必要数のスタンプがたまっていれば、注文時に特典を選べる）
7. 注文を確定し、決済を完了する。

[システム]

8. 特典を利用した場合、注文確定のタイミングで、必要数を満たした未使用のリワードカードのうち
   最も古い1枚を「使用済み」とする。
9. 特典を利用した注文がキャンセルされた場合、そのカードを「未使用」に戻す。

[店舗スタッフ]

10. 商品を会員に受け渡す。

[システム]

11. 受け渡し完了のタイミングで、特典対象以外の商品が含まれていれば、その注文にスタンプを1個発行する。
12. 押す先は、その会員が持つ、期限内・未使用・満杯でないカード。
    無ければ、配布期間内であることを確認して新しいカードを作る。

[会員]

13. 期間限定の種別が開催中であれば、参加するかどうかを選ぶ（開催ごとに一度だけ）。

[システム]

14. 参加を選んだ場合、いま貯めているカードの種別を切り替え、有効期限に開催期間の長さを加算する。

[例外・ルール]

- カードの有効期限は、できた日 ＋ 種別が定める有効期間で確定し、以後延長しない。
  期間限定の種別に参加したときだけ、開催期間の長さを加算する。
- 満杯になったカードの特典は、カードの有効期限 ＋ 種別が定める延長期間まで使える。
  早く貯めた会員ほど、使える残り期間が長い。
- 貯めている途中のカードは常に1枚。複数の種別を並行して貯めることはできない。
  満杯になったカードは、使うまで複数枚たまることがある。
- 新しいカードを作れるのは、種別の配布期間中に限る。
- 1枚に押せるスタンプは種別が定める必要数まで。1回の注文で使えるカードは1枚まで。
- 特典対象の商品しか含まない注文にはスタンプを付与しない。
  対象外の商品が1つでも含まれていれば1個付与する。
- 特典は対象商品1点に1つ。対象商品の代金を超えて割り引かない（マイナスにしない）。
  対象かどうかは商品側で決める。
- 全店舗の注文がスタンプ付与の対象になり、貯まったスタンプはどの店舗でも使える。
- スタンプの消費は注文確定時、付与は受け渡し完了時。
  消費は「使う宣言」なので早めに押さえ、付：wq与は「受け取った事実」への対価なので後になる。
